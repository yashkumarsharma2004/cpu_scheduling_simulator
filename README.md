CPU Scheduling Simulator (Python)

A Python-based simulator implementing classic CPU Scheduling Algorithms used in Operating Systems.
This project calculates all essential process scheduling metrics and generates ASCII Gantt Charts for visual understanding.

🚀 Features

✔ Implements the following algorithms:

FCFS – First Come First Serve

SJF (Non-preemptive)

SJF / SRTF (Preemptive)

Priority Scheduling (Preemptive & Non-preemptive)

Round Robin (user-defined time quantum)

✔ Calculates:

Completion Time

Turnaround Time

Waiting Time

Average WT & TAT

✔ Shows ASCII Gantt Chart
✔ Accepts sample or custom input
✔ Clean code (fully commented)
✔ Ideal for mini-projects, OS labs, and college submissions
