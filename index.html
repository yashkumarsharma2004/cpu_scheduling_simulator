CPU Scheduling Simulator

About the Project

This project simulates major CPU scheduling algorithms such as FCFS, SJF, SRTF, Priority (preemptive & non-preemptive), and Round Robin.

  • Waiting Time, Turnaround Time, Completion Time
  • ASCII Gantt Chart output
